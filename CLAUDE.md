# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Static site (French UI) charting, since 2000, for GR/IT/ES/PT/IE/FR/DE: 10-year bond spreads vs Germany and 10-year rates (monthly), public debt (% GDP, quarterly), public deficit split into primary deficit + interest (% GDP, rolling 4 quarters, one country at a time, back to 1950), nominal GDP growth (inflation + real growth) vs apparent interest rate on public debt (one country at a time, back to 1950), the same vs the apparent rate on all non-financial debt (government + non-financial corporations + households, since 2000), public debt held by the Eurosystem by programme, SMP / PSPP / PEPP (% of public debt, since end 2012, euro area or one country), GDP by expenditure Y = C + I + G + (X − M) (one country at a time, % of GDP or Md€, back to 1950), euro-area M3 growth and its counterparts (monthly, since 1999), plus a second page (`budget.html`, currently hidden: link commented out in `index.html`, file removed before Pages deploy) with Sankey diagrams of French public revenue and spending. No build step, no dependencies, no tests. The user communicates in French; keep UI text, comments and commit messages in French.

## Commands

- View the site: open `index.html` directly in a browser (`file://`). No server needed.
- Refresh data: `python3 update.py` (stdlib only). Rewrites `data/data.js`, `data/budget.js` and `data/cache.json`.
- Headless screenshot to check rendering (Firefox is a snap here, so the profile must live under `~/snap/firefox/common/` and the output path must not be a dotfile):
  `firefox --headless --no-remote --profile ~/snap/firefox/common/<prof> --window-size=1400,900 --screenshot "$PWD/shot.png" "file://$PWD/index.html"`

## Architecture

- **Data pipeline (`update.py`)**: ECB SDW API (official monthly long-term rates, ~1 month lag) → CNBC daily closes → TradingView live quote. Months after the last ECB month are filled with the average of daily values (`merge()`). Debt (`gov_10q_ggdebt`) comes from the Eurostat JSON-stat API; Greece is `EL` there. The deficit is computed in `rolling_deficit()` as −Σ4q B9 (`gov_10q_ggnfa`, MIO_EUR, NSA) / Σ4q GDP (`namq_10_gdp`), so deficit > 0. At Q4 it matches the annual official figure within 0.1 pt. Years without quarterly data (IE, DE before 2002) fall back to annual `gov_10dd_edpt1` at Q4. Quarterly SCA % GDP was rejected because Italy is missing. `growth_vs_rate()` computes, over rolling 4 quarters, nominal and real GDP growth (Σ4q GDP, CP_MEUR / CLV10_MEUR, vs Σ4q a year earlier) and the apparent rate (Σ4q `D41PAY` / debt in MIO_EUR a year earlier); output keys `growth`, `real` and `interest`. Before 2000 it uses annual figures placed at Q4 (`fetch_history()`, 1950-1999, kept from the cache if the download fails): interest paid and debt in % GDP from the IMF datamapper FPP dataset (`ie`, `d`; the IMF returns 403 to browser user agents, hence `curl/8`), nominal and real GDP from the Global Macro Database CSV (~30 MB); rate = ie_t / d_{t−1} × (1 + nominal growth). Debt (`history_debt()`, FPP `d`, end of year at Q4) also goes back to 1950 with annual figures before 2000; so does the deficit (`rolling_deficit()`: IMF `ie` − `pb`, interest minus primary balance, annual at Q4 for 1950-1999). `total_rate()` (output key `interest_all`): Σ4q interest paid by S11 and S14_S15 (`nasq_10_nf_tr` D41 PAID) + S13 `D41PAY` / F3+F4 liabilities of S11, S14_S15, S13 a year earlier (`nasq_10_f_bs`, non-consolidated); D41 excludes FISIM, so it is a bit below bank rates. `fetch_qe()` reads the ECB PSPP and PEPP breakdown CSVs (first table: monthly net purchases per jurisdiction, Greece only in PEPP); it also returns `other` (sum of the other euro-area countries) and `supra` (« Supranationals »); `fetch_smp()` reads the ECB SMP file (year-end book value per country, Md€, IE/GR/ES/IT/PT + `total`, from 2012). `qe_holdings()` (output key `holdings`, `{periods from 2012-12, PSPP: {XX|other|supra: [Md€]}, PEPP: {…}, SMP: {XX|total: [Md€]}}`) gives cumulative net purchases per issuer, SMP interpolated monthly between year ends (last value held), and `debt` (Md€, per country and `EA` = Eurostat `EURO_AREA` « EA21 », fetched as `debt_ea` via `fetch_eurostat(..., countries=[...])`) at month end via `month_end_value()`. `money()` (output key `money`, `{periods: ['AAAA-MM'], m3, private, government, external, other}`): euro-area M3 growth over 12 months and contributions of its counterparts, i.e. 12-month flows (ECB BSI via `fetch_bsi()`, `MONEY` keys: M3 stock and flow, credit `AT2` to the private sector `2200` and to general government `2100`, net external assets `A80`, MFI sector `U` so Eurosystem bond holdings count) / M3 stock a year earlier; `other` is the remainder (mostly longer-term bank liabilities); the flow-based growth matches the official one. The ECB data API blocks wildcards and runs of empty key dimensions (HTTP 400): query exact keys or a single empty dimension. `demand()` (output key `demand`, `{periods, series: {XX: {C, I, G, X, M}}}` in Md€, 4 decimals): Σ4q `namq_10_gdp` CP_MEUR NSA P31_S14_S15, P5G, P3_S13, P6, P7 since 2000, GMD `hcons`, `inv`, `gcons`, `exports`, `imports` (already in euros) at Q4 for 1950-1999; the front end takes Y as the sum of the components because GMD's statistical discrepancy reaches several points in the 1950s (Spain 23 %). `interest_burden()`: Σ4q `D41PAY` / Σ4q GDP, annual `gov_10a_main` D41PAY % GDP at Q4 for years without quarterly data (IE, DE 2000-2001), IMF `ie` before 2000. If the download fails, it falls back to `data/cache.json`. Output is a JS file (`window.DATA = {months, series, debt: {periods, series}, deficit: {periods, series}, names, fetched}`), **not JSON**, because `fetch()` is blocked on `file://`. Keep it that way so double-clicking `index.html` keeps working.
- **Front end**: `index.html` loads `assets/plotly.min.js` (vendored), `data/data.js`, then `assets/app.js` as classic scripts sharing globals.
  - `app.js` builds one Plotly figure from the `PANELS` array (spreads, rates, debt, deficit, demand, growth vs rate, Eurosystem holdings by programme, M3; the user removed Moody's ratings, debt maturity and QE-share-of-debt panels, and merged the deficit and interest burden panels). Plot height is 42 % of the window, clamped to 320-500 px. Single-country panels (`single`) define `traces(c)` (merged with axis/x defaults by `singleTraces()`) and `tip(c, i)`; only those with `history` (the growth panels) get `HISTORY` events. The demand panel (`demandPanel`) stacks C, I, G areas then a hatched (`fillpattern`) X − M band between C + I + G and the GDP line, in % of GDP or Md€ (`state.unit`, `<select class="unit">` next to the country select inside `.picks`, saved in `localStorage`); `fromZero` makes `autoRanges()` keep 0 as the lower bound. The holdings panel (`holdingsPanel`) stacks the programmes (`PROGRAMS`: SMP `--s5`, PSPP `--s1`, PEPP `--s2`) in % of public debt with a total line, for the euro area (`EA`: all member states, supranationals excluded, over euro-area debt) or one country (`state.holder`, saved in `localStorage`, independent of `state.pick` and the legend); its `place` is a function. Title selects come from `selectsOf(panel)`: `panel.selects()` or, by default for a `single` panel without `place`, the unit (if `units`) and country; each `<select data-state="key">` writes `state[key]` and `localStorage[key]`. Objects in `PANELS` are copies (`stamps` is added there), so panel code must read `PANEL.key.stamps`, not the original object's. The money panel (`moneyPanel`) is `single` with `place: "zone euro"`: no country select, the tooltip header shows the place; positive contributions stacked above 0, negative ones hatched below (`splitAtZero()` on all four), M3 growth as a line, plotted at the middle of its 12 months (`monthMid`, tooltip `monthWindow`). The deficit panel (`deficitPanel`, `DEFICIT`) is single-country: primary deficit = deficit − interest burden (`DATA.burden`, aligned by period, so the burden's 1950-1999 history is no longer drawn) as an area from 0 (hatched when it is a primary surplus), interest stacked on top up to the total deficit line; traces use only known periods (own `x`), so IE/DE annual points before 2002 are joined. `hatch()`/`hatched()` give the Plotly fill pattern and tooltip swatch shared with the demand panel. Wherever an area is split into positive (solid) and negative (hatched) parts (growth, deficit), `splitAtZero()` first inserts the zero-crossing points (all series interpolated linearly, x as « YYYY-MM-DD HH:MM »), otherwise the clipped areas overshoot their outline. The two growth panels (`growthPanel()`: `growth` with the public-debt rate, `growthAll` with the all-debt rate, `panel.rate`) are `single` and share `state.pick`. The growth panel is `single`: it shows one country only (`state.pick`, `<select class="pick">` at the right of its title, saved in `localStorage`, independent of the legend), as stacked areas inflation (GDP deflator = nominal − real growth, `--s2`, 0 → inflation) and real growth (`--s3`, → nominal growth), each split into a solid positive part and a hatched negative part, a solid `--text-primary` line for nominal growth, plus the apparent rate as a dotted line; its traces have no `legendgroup` and its tooltip comes from `panel.tip(c, i)`. Growth panels (`rg`) get a light background from `rgShapes()`: `--s5` tint where r (apparent rate) > g (nominal growth), `--s1` where r < g, each point covering halfway to its neighbours, gaps in r interpolated like the dotted line; the tooltip adds a one-line r/g reading. Its values (rolling 4 quarters, or annual before 2000) are plotted at the middle of their window (`windowMid`, so 1980 is drawn and hovered in 1980, not at its end) and the tooltip date is the window (`windowLabel`: « année 1980 », « avril 2009 → mars 2010 »). Panels missing from the saved order are appended; saved keys of removed panels are ignored. Display order (`state.order`) and folded panels (`state.folded`) are user-controlled and saved in `localStorage`. `render()` assigns axis suffixes (`x`/`y`, `x2`/`y2`…) only to unfolded panels (`shown`), in display order, and lays them out in pixels via `geometry()`: title band, plot, time-axis band. It then sets the chart height and keeps the x range (and y ranges in manual scale). X-axes are linked via `matches`. Anything iterating panels (fitY, hitTest, setX, hover) must use `shown`, not `PANELS`. Event lines are Plotly shapes; their labels are HTML (`paintEvents()`, `#events`), on one line at the top of every shown panel for general events (country-specific ones only on the first shown panel), truncated with an ellipsis when they would touch the next one (never shifted down), repainted on `plotly_afterplot` and `plotly_relayouting`. Hovering a label shows `#evtip` with the event's 3rd element (what it does on the charts and why, « Effet : » starts a paragraph). Events may have a 4th element, a country code: they are drawn (line and label in the country's colour) only when that country is shown in the legend (`visibleEvents()`), which is why toggling the legend calls `render()`, not a restyle. The user wants no France-specific events in `EVENTS`. The `single` panel also gets `HISTORY(state.pick)` events with their labels (1973 and 1979 oil shocks; for France, Trente Glorieuses and the 1983 tournant de la rigueur). Hovering outside a panel's data range shows only the vertical line, no tooltip. Initial view starts in 2000 (`START`); spreads and rates start in 2000, debt, deficit and growth in 1950. Panels may define `date(i)` for the tooltip date: debt shows « fin 1975 » before 2000; deficit, like growth, is plotted at the middle of its window (`windowMid`/`windowLabel`). In auto scale, `render()` computes y ranges (`autoRanges()`) before `Plotly.react` so there is a single draw.
  - Chart titles are HTML (`#titles`, absolutely positioned over `#stage`), not Plotly annotations. They hold a −/+ fold button shown on hover; folding and unfolding are immediate (the user removed the fade animations) and fold buttons act on `pointerdown`, not click. Dragging a title (HTML5 drag & drop on `#stage`, `#dropline` indicator) reorders panels. Hovering a title's text (not the fold button) shows `#evtip` (class `info`, wider) with `panel.info` from `INFO`, built by `explain()`: what the chart means, formulas (`.f` blocks, kept short at the user's request: none for spread and rate, debt in euros ΔD = r × D + primary deficit, just « g > r » for growth, none for deficit and growthAll) and « À observer » with figures checked against the data; below the title, or above it when it would not fit in the window. Keep these texts in sync when a chart changes, and avoid figures that the daily update would make stale.
  - The legend is custom HTML (`#legend`) in the sticky page header, not Plotly's: click toggles a country in every panel (`state.hidden`; only FR and DE are shown on load), double-click isolates it while keeping Germany as the reference.
  - Axis interaction is custom, TradingView-style: `hitTest()` maps mouse position to the y-axis band, x-axis band or plot area. Dragging an axis rescales it; on the time axis the right edge stays fixed and the grabbed date stays under the mouse (`grabX()`). The mouse wheel never rescales axes, so page scrolling is never captured; only Ctrl + wheel over a plot zooms time. On touch screens, one finger always scrolls the page (all touch events are stopped in the capture phase on `#chart` so Plotly never pans; CSS `touch-action: pan-y`), two fingers pinch-zoom and pan time like a photo: the date under the midpoint stays there and the scale follows the finger distance exactly, computed from the gesture start (no overshoot). `fitY()` auto-fits y to visible data while `state.autoY` is on. The "Échelle auto" button is only shown when autoY is off.
  - Hover is custom (`hovermode: false`): an HTML overlay (`#hover` in `#stage`) draws a dashed vertical line across every panel, a dashed horizontal line when the hovered panel shows a single series, and a tooltip for the hovered panel, updated once per animation frame. It shows the nearest point of each visible series, sorted by value. Plotly spikes and hover labels are off.
  - Theming: CSS custom properties in `assets/style.css`, with dark mode via `prefers-color-scheme` overridden by `:root[data-theme]`. The choice is persisted in `localStorage`. Plotly colors are read from CSS vars at layout build time, so a theme change must rebuild `baseLayout()` and re-render.
  - Series colors map to `--s1..--s7` in the order GR, IT, ES, PT, IE, FR, DE (`COLOR()` in `app.js`, matching `COUNTRIES` order in `update.py`).
- **Budget page (`budget.html`, `assets/budget.js`)**: `budget()` in `update.py` combines, for France (annual, MIO_EUR, S1311 État + ODAC, S1314 sécurité sociale, S1313 collectivités): revenue by item from `gov_10a_main` (`REVENUES`, last item = residual TR − named items − transfers received) and spending by function from `gov_10a_exp` (COFOG level 2 grouped in `FUNCTIONS`; R&D of every function goes to "Recherche"). Own spending per function = TE − intra-government transfers of that function (`D4/D7/D9_S13xx`), which Eurostat only publishes from 2009, and COFOG lags a year, hence years 2009 → n−2. Transfers between sectors (the "Reçu/Versé" nodes) come from `gov_10a_main` payer side. Imputed pension contributions (`IMPUTED` = D61 − D611 − D613, i.e. the État paying its own civil servants' pensions) are a separate revenue item and are split out of each function pro rata to compensation (D1), military defence weighted by the CAS Pensions rates (`MILITARY_WEIGHT`). Output `data/budget.js` (`window.BUDGET`, Md€: `rev`, `exp`, `imp`, `to`, `balance` per sector and year). Small negative residuals are skipped when drawing; COFOG and main vintages can differ by ~1 Md€.
  Two Plotly sankeys: consolidated (revenues → one "Administrations publiques" node → functions, link colour = collecting/spending sector, transfers eliminated) and unconsolidated (one block of nodes per sector in its colour, with "Reçu de…"/"Versé à…" transfer nodes in the counterpart's colour). Each function node is followed by its "↳ cotisations retraite imputées" node (`--s4`) when ≥ 0.5 Md€. Node positions are set explicitly (`arrangement: "fixed"`); chart height grows with the busiest column. Plotly node labels are empty: `placeLabels()` draws HTML labels outside the diagram (left/right, pushed down to avoid overlap; above middle nodes), under the transparent Plotly layer so its hover label stays on top, re-placed on `plotly_afterplot`. Sector colours: État `--s1`, Sécu `--s3`, collectivités `--s6`, déficit `--s2`.
  Below them, "Protection sociale et déficit" (`drawSocial()`): spending of the 6 social functions (all sectors, imputed contributions included) vs dedicated revenue (social and imputed contributions of all sectors + the Sécu's CSG, sales and other revenue; the Sécu's other taxes, i.e. affected VAT etc., count as social or as State revenue depending on the `#affect` toggle, saved in `localStorage`). Horizontal Plotly waterfall for the selected year (values in the y labels) + line chart since 2009 (social balance, rest, public deficit).
- **Deployment**: `.github/workflows/update.yml` runs `update.py` on weekdays at 18:00 UTC (or manually), commits `data/`, then deploys the repo root to GitHub Pages (Pages source must be "GitHub Actions"). Pushes to `main` only redeploy. Never push unless the user asks.

## UI preferences

The user wants a minimal ("épuré") page: no explanatory grey notes; the only footer is the one-line « Données au … · Sources : … » at the bottom of `index.html` (keep the source list in sync when adding data); monthly resolution with lines only, one title per chart plus a global title, and no extra control buttons.
